Lab 174 - Escalando e Balanceando Carga da Sua Arquitetura

Amazon EC2 Elastic Load Balancing EC2 Auto Scaling CloudWatch

Visão geral

Este laboratório apresenta recursos da AWS para distribuir o tráfego de aplicações e ajustar automaticamente a capacidade computacional conforme a demanda.

Application Load Balancer

Recebe as solicitações e distribui o tráfego entre os destinos registrados.

Launch Template

Define as configurações utilizadas para iniciar novas instâncias EC2.

Auto Scaling Group

Gerencia a quantidade de instâncias e ajusta a capacidade da aplicação.

CloudWatch

Monitora métricas que podem orientar as políticas de escalabilidade.

Fluxo da arquitetura

Usuários
↓

↓

CloudWatch - Monitoramento

Desafio opcional - AWS CLI

Criação de uma Amazon Machine Image (AMI) a partir de uma instância EC2, utilizando AWS CLI. A imagem foi consultada até atingir o estado available.
